# Hormozi Frameworks — a Claude Skills Bundle

An on-demand set of **Claude skills** that turn Alex Hormozi's $100M business frameworks into working advisors you can run inside Claude (Claude Code, Cowork, or claude.ai). Built from the framework structure of his three books and enriched with his current 2025–2026 public material, so the thinking is up to date, not stuck in 2021.

Point Claude at a problem — an offer to sharpen, a lead engine to build, a money model to design, a brand to grow — and the relevant skill loads the matching Hormozi framework and works the problem with you.

## How to install

**Claude Code / Cowork**
1. Copy each folder inside `skills/` into your skills directory: `~/.claude/skills/`
2. Reload. Each skill auto‑triggers on its topic, or invoke it explicitly with `/<skill-name>` (e.g. `/hormozi-advisor`).

**claude.ai (web) or the Cowork uploader**
- Zip a single skill folder and upload it, or add it to a Project's skills.

Each skill is a `SKILL.md` (the advisor persona + the framework). The flagship `hormozi-advisor` also ships a `references/` folder of deeper framework notes.
